# StudioCar AI

Production-oriented automotive image processing built as a pnpm and Turborepo monorepo.

## Requirements

- Node.js 24 or newer
- pnpm 12.3.4

## Workspace commands

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm test:integration
pnpm build
pnpm e2e
```

Product and architecture requirements live in [`docs/`](./docs/).
